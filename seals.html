Daily seals

Proof that the record was written when we say it was, and has not been changed since.

Why and howWhy: a track record is only worth something if nobody - including us - can quietly rewrite an old forecast after the outcome is known.
How: at the end of every day (UTC) the program writes a plain list of everything captured that day: each source link, the fingerprint (SHA-256) of the captured text, when it was said and when we captured it. The fingerprint of that list is the day's seal. Each list begins with the previous day's seal, so the days form a chain: changing any old entry would change every later seal. The seal is also sent to OpenTimestamps, which anchors it in the Bitcoin blockchain - an independent, public clock.
Check it yourself: download a day's list and its proof, then run ots verify YYYY-MM-DD.txt.ots with the free OpenTimestamps client (a proof needs a few hours to be confirmed by Bitcoin; the client's upgrade command completes it).
Honest limit: history collected in November 2026 is sealed on the day we captured it, so for old speeches the seal proves what the official text said when we read it, not when it was first spoken.
