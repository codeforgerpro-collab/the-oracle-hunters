Verify a daily seal yourself

  1. Open Daily seals and save a day's list (2026-11-16.txt) and its proof (2026-11-16.txt.ots).
  2. Compute the list's fingerprint - sha256sum 2026-11-16.txt on Mac or Linux, certutil -hashfile 2026-11-16.txt SHA256 on Windows. It must equal the seal shown for that day.
  3. Install the free OpenTimestamps client: pip install opentimestamps-client.
  4. Run ots verify 2026-11-16.txt.ots. It names the Bitcoin block in which the seal was anchored - a public clock that nobody controls, including us.
  5. Each list starts with the previous day's seal, so changing any old entry would break every seal after it.

A well-calibrated speaker's “80%” comes true about 80% of the time. “Close” verdicts count as half.

A speaker gets a score only after at least 10 of their statements have been checked - two lucky calls rank nobody.
